## データフロー詳細

### Phase 1（MVP）

```
企業名
  │
  ▼
[EDINETコードリストCSV]
  EDINETコード（Exxxxx）取得
  ├─ 完全一致 → 採用
  ├─ 前方一致 → 採用
  └─ 部分一致 → 採用
  │
  ▼
[書類一覧API]
  直近400日を遡ってスキャン
  ordinanceCode="010" & formCode="030000" でフィルタ
  → docID 取得
  │
  ▼
[書類取得API]
  type=2（PDF）でダウンロード
  ZIPを解凍 → 本文PDF抽出（最大ファイルサイズ）
  │
  ▼
[pdfplumber]
  "事業等のリスク" 〜 "経営者による財政状態" を抽出
  │
  ▼
[LLM分析]
  8カテゴリへの分類
  リスク評価（High/Medium/Low）
  根拠の記述
  │
  ▼
[Markdownレポート]
  Discord へ出力
```

### Phase 2（予定）

```
企業名
  │
  ├─ [Phase 1のフロー] → 法的リスク分析
  │
  └─ [XBRL/CSV取得 type=5]
       jpcorp_cor タクソノミー要素を直接パース
       5期分の財務トレンドを構造化データとして取得
       → 財務・ガバナンス等の追加カテゴリを分析
```

## コンポーネント一覧

| コンポーネント | 技術 | 役割 |
|-------------|------|------|
| エージェント基盤 | ISEAI（OpenClaw / Alibaba Cloud） | エージェント実行環境 |
| チャネル | Discord Bot | ユーザーインターフェース |
| データ取得 | EDINET API v2（金融庁） | 有価証券報告書の取得 |
| PDF解析 | pdfplumber（Python） | リスクセクションの抽出 |
| LLM | Claude（Anthropic API経由） | 法的リスクの分析・評価 |
| スクリプト | Python 3.11+ | edinet_fetcher.py |

## セキュリティ考慮事項

- `EDINET_API_KEY` は環境変数で管理し、コードにハードコーディングしない
- 対象は公開情報（EDINET）のみ。機密情報・非公開情報は一切取り扱わない
- Discord Bot Token は ISEAI の設定画面で安全に管理する
