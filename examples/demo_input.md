# デモ入力サンプル

Clawathon Tokyo Edition デモで使用する入力コマンドのサンプルです。

---

## Case 1: リスクが高い企業（HODL1）

```
/dd 株式会社HODL1
```

**期待される結果の特徴:**
- 継続企業前提: 🔴 High（GC重要事象あり）
- 訴訟・法的紛争: 🔴 High（総額33億円超の訴訟）
- ガバナンス: 🔴 High（2025年に経営陣全面交代）
- コンプライアンス: 🔴 High（旧経営陣の不正行為認定）

**デモでの活用**: リスクが高い事例として、エージェントが構造化できることを示す。

---

## Case 2: リスクが低い大企業（比較用）

```
/dd トヨタ自動車
```

または

```
/dd 株式会社メルカリ
```

**期待される結果の特徴:**
- 多くのカテゴリで 🟢 Low または 🟡 Medium
- Case 1 との対比で「リスクの差が可視化される」ことを示す

**デモでの活用**: Case 1 と比較し、レポートが企業ごとに異なる評価を出すことを示す。

---

## Case 3: 自然文入力（OpenClawの柔軟性をアピール）

```
メルカリの法的リスクを調べて
```

```
ソフトバンクグループのDDレポートを作成してください
```

**デモでの活用**: コマンド形式だけでなく自然文でも動作することを示す。

---

## バックアップ用（ライブデモ失敗時）

EDINET API の応答遅延やタイムアウトに備えて、
`examples/demo_output.md` に事前生成済みのサンプル出力を保存しておく。

ライブデモが失敗した場合は `demo_output.md` のサンプルを提示しつつ、
「実際にはこのような出力が生成されます」と説明する。
